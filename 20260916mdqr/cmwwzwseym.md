# 【问答时间】自从上次咨询糖尿病饮食后，我又来了······

> 更新时间：2026-09-16 (UTC+8)

你好！自从上次咨询糖尿病饮食问题之后获益匪浅啊！这次我想问一下人们所说的“富贵病”之一的痛风，在饮食方面要注意哪些问题？我想很多朋友也想了解这方面的知识吧！

你好！痛风病人（高尿酸血症的朋友也可以参考），平时应以低嘌呤饮食（蔬菜、脱脂、低脂奶及其制品）为主，严格限制动物内脏、海产品和肉类等高嘌呤食物的摄入。比如嘌呤含量较高的熏火腿、牛肉、鸡汤、鸭、肝、羊肉等食物少吃。瘦肉可煮沸去汤后食用。多喝水，建议每日饮水 2000 ml 以上，保证每日尿量 2000～3000 ml。

可以吃水果吗？

可以的，吃水果可以补充维生素C和钾，利于尿酸排出。水果可食用含果糖较少的水果，如樱桃、草莓、菠萝、桃子等。但应该注意控制摄入量，一般来说每天水果摄入量为一到两个拳头大小较为宜。

还能喝酒吸烟吗？

酒精摄入、吸烟会增加痛风发作风险，强烈建议戒酒戒烟。

那血尿酸应该怎么控制？

高尿酸血症及曾经痛风发作患者，需将血尿酸长期控制在适宜水平，并且监测血清尿酸值。一般建议将血尿酸控制在持续低于 360μmol/L 的水平。对于严重（痛风石、慢性关节病、经常发作 ) 的痛风患者，血清尿酸水平应低于 300μmol/L。控制尿酸水平及预防痛风发作的药物方案可到我院内分泌科找专科医生制定。

那痛风还应该注意什么事项吗？

痛风病人一般还伴有超重、高胆固醇血症等其他问题，除了注意饮食外，还应该规律运动，控制体重【一般认为BMI值控制在18.5-23.9范围内较好，计算公式：BMI=体重（KG）/身高（M2）】。
